# VATRadar 개인정보처리방침

최종 수정일: 2026-07-30

VATRadar(이하 "앱")는 VATSIM 네트워크의 공개 데이터를 조회해 보여주는 비상업적 앱입니다.
이 문서는 앱이 어떤 정보를 다루는지 설명합니다.

## 요약

**앱은 계정을 만들지 않으며, 이름·이메일·전화번호·위치 등 개인을 식별할 수 있는 정보를
수집하지 않습니다.** 사용자가 입력한 설정값은 모두 기기 안에만 저장됩니다.

## 기기에 저장되는 정보

아래 항목은 **기기 내부에만** 저장되며 외부로 전송되지 않습니다.
앱을 삭제하면 함께 지워집니다.

| 항목 | 용도 |
|---|---|
| SimBrief ID (별칭 또는 Pilot ID) | 사용자가 SimBrief에서 만든 비행계획을 불러올 때 사용 |
| VATSIM CID | 뽑은 경로를 실제로 비행했는지 확인 |
| 챌린지 기록·포인트·등급 | 앱 내 보상 진행 상황 |
| 관심 관제소 목록 (예: RKSI) | 해당 관제소 접속 시 알림 |
| 언어·화면 모드 설정 | 앱 표시 설정 |
| 전 세계 공항 데이터베이스 | 경로 추천 및 지도 표시 (앱에 동봉된 공개 데이터) |

## 외부로 전송되는 정보

| 대상 | 전송 내용 | 목적 |
|---|---|---|
| VATSIM (`data.vatsim.net`, `my.vatsim.net`) | 없음 (조회만) | 실시간 트래픽·관제·이벤트 정보 |
| VATSIM METAR, NOAA 항공기상 | 공항 ICAO 코드 | 기상 정보 조회 |
| SimBrief (`simbrief.com`) | 사용자가 입력한 SimBrief ID | 해당 계정의 비행계획 조회 |
| Google Maps | 지도 표시에 필요한 요청 | 지도 렌더링 |
| Firebase Cloud Messaging | 기기 등록 토큰, 구독한 관제소 코드, VATSIM CID | 관제소 접속·챌린지 완주 알림 수신 |
| 챌린지 감시 서버 (Cloudflare Workers) | VATSIM CID, 뽑힌 경로의 출발·도착 공항 | 비행 완주 여부 확인 |
| VATSIM Connect (`auth.vatsim.net`) | 로그인 정보 (VATSIM에 직접 입력) | 계정 소유 확인 |

SimBrief ID는 사용자가 직접 입력한 경우에만, 그리고 사용자가 "OFP 가져오기"를 누른
시점에만 SimBrief로 전송됩니다.

## VATSIM 계정 연결 (선택)

설정에서 "VATSIM 계정으로 로그인"을 누르면 브라우저가 열리고 VATSIM 공식 로그인
화면으로 이동합니다.

- **비밀번호는 앱을 거치지 않습니다.** 앱 안의 화면(WebView)이 아니라 실제 브라우저가
  열리므로, 주소창에서 vatsim.net인지 직접 확인할 수 있고 앱은 입력값을 볼 수 없습니다.
- 로그인 후 감시 서버가 받는 것은 **CID 하나뿐**입니다. 이름·이메일 권한은 요청하지
  않습니다.
- VATSIM 액세스 토큰은 CID를 확인한 직후 버리고 저장하지 않습니다. 서버에 남는 것은
  기기를 알아보기 위한 무작위 토큰과 CID뿐입니다.
- 설정에서 "연결 해제"를 누르면 서버에 있던 토큰도 함께 삭제됩니다.

연결하지 않아도 CID를 직접 입력해 앱을 쓸 수 있습니다. 연결은 그 CID가 본인 것임을
확인해, 남의 CID로 챌린지 보상을 받는 것을 막기 위한 것입니다.

## 챌린지 완주 확인

앱에서 경로를 뽑으면, 그 경로를 실제로 비행했는지 확인하기 위해 감시 서버에
**VATSIM CID와 해당 경로의 출발·도착 공항**을 등록합니다.

- VATSIM CID는 이미 VATSIM이 공개 데이터로 제공하는 식별자입니다.
- 서버는 이름·이메일 등 다른 정보를 저장하지 않으며, FCM 토큰도 저장하지 않습니다.
- 등록된 감시 기록은 **완주 확인 시 즉시 삭제**되고, 그렇지 않아도 **48시간 뒤 자동 삭제**됩니다.
- 설정에서 VATSIM CID를 비우면 이후 등록이 중단됩니다.

포인트와 등급은 서버가 아니라 **기기 안에서만** 계산·보관됩니다.

## 알림 서비스

관제소 접속 알림을 켜면 앱은 Firebase Cloud Messaging(FCM) 토픽을 구독합니다.
이때 전송되는 것은 **어떤 관제소를 구독하는지**와 **기기 식별용 FCM 토큰**뿐이며,
사용자를 식별할 수 있는 정보는 포함되지 않습니다.

알림 서버는 VATSIM의 공개 관제사 목록만 조회하며, 사용자별 정보를 저장하지 않습니다.

## 권한

| 권한 | 사용 이유 |
|---|---|
| 인터넷 / 네트워크 상태 | VATSIM·기상·지도 데이터 조회 |
| 알림 (Android 13 이상) | 관제소 접속 알림 표시. 거부해도 나머지 기능은 정상 동작합니다 |

위치 권한은 요청하지 않습니다.

## 광고·분석

앱은 광고를 표시하지 않으며, 사용자 행동 분석 도구를 포함하지 않습니다.

## 아동 개인정보

앱은 아동을 대상으로 하지 않으며, 연령 정보를 수집하지 않습니다.

## 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 설정이 함께 삭제됩니다.
알림 구독을 끊으려면 앱 내 알림 페이지에서 등록한 관제소를 삭제하거나 알림을 끄면 됩니다.
