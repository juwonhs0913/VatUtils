# VATFlight

VATSIM 네트워크를 이용하는 가상 조종사를 위한 안드로이드 앱입니다.
실시간 관제·트래픽 지도, 무작위 경로 추천, 관제소 접속 알림, 기상 정보를 담고 있습니다.

An unofficial Android companion app for pilots flying on the VATSIM network.
